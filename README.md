# ASCP v6.3 — September Update

> **Release:** ASCP v6.3 
> **Codename:** AEGIS
> **Platform:** Android 17 
> **Release Type:** Official
> **Security Patch:** September 2026

---

## ✨ Highlights

- Merged the latest **September Security Patch**.
- Added **Smart Pixels** support.
- Added **Smart 5G** service.
- Switched to **ASCP Launcher (Launcher3)** as the default launcher, replacing Pixel Launcher, with a wide range of customization features.
- Updated **Obscura Privacy Manager** to **v2.0**.
- Introduced **Personalizations** — the new ASCP customization hub.
- Improved **Recents animation** for a smoother experience.
- Added **ASCP Quick Launch**, inspired by OEM implementations.
- Added **OmniJawsClient**.
- Implemented **status bar and navigation bar burn-in protection**.

---

## 🎨 Personalization & UI

- Added the ability to change the **gesture navigation bar length**.
- Added support for **3-button navigation layout settings**.
- Added an option to change the **gesture navigation bar height**.
- Added a **system-wide blur intensity slider**.
- Added **NothingOS-style themed icons**.
- Added **iOS-style app folders** in the app drawer.
  - Toggleable through ASCP Launcher settings.
- Added **OEM-style large folders**.
- Added **depth wallpaper** support.
- Added **Smart Island** with:
  - Dynamic Island
  - Dynamic Chip
- Added **Heads Up timeout and snooze** controls.
- Added **Heads Up blacklist** support.
- Added **Less Boring Heads Up** option.
- Added **Ambient notification timeout**.
- Added an option to **suppress notification sounds and vibration while the screen is ON**.

---

## 📸 Screenshot Improvements

- Added a toggle to **copy screenshots directly to the clipboard** instead of saving them to storage.
- Added an option to **hide the status bar while capturing screenshots**.

---

## ⚙️ System & Advanced Features

- Introduced **TEE Simulator**.
- Added **advanced CPU/GPU model spoofing**.
- Added **Wi-Fi timeout** feature.
- Added **Bluetooth timeout** feature.
- Added support for **Private Space enrollment**.
- Added support for changing system-wide **blur intensity**.
- Added support for **OmniJawsClient**.

---

## 🔋 Power & System Apps

- Redesigned the **Power Insights** user interface.
- Redesigned the **System Updater** page.

---

## 🛠️ Fixes & Improvements

- Fixed lockscreen blur for the **device entry icon and shortcuts**.
- Fixed **Heads Up notification timeout** on Ambient Display.
- Fixed **clock and carrier text vertical padding**.
- Fixed **silent toggle** not working in Status Bar Tuner.
- Fixed **shade header battery spacing**.
- Fixed **clock start padding with date** in the expanded Quick Settings panel.
- Fixed **lockscreen Quick Settings disable** and **secure tile unlock requirement** for Dual Shade & Scene Container.
- Fixed **brightness slider position** during QQS → QS transition.
- Fixed **Ripple effect** not working in certain scenarios.
- Fixed **SystemUI freeze** on some devices.
- Fixed **navigation gesture getting stuck** in certain cases.
